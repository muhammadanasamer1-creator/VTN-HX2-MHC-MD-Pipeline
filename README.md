# VTN-HX2-MHC-MD-Pipeline
This repository contains the 40 ns molecular dynamics simulation data for the vitronectin hemopexin-2 (HX2) domain complexed with MHC-I and MHC-II receptors. This structural analysis supports an MPhil thesis for a potential liver cancer vaccine candidate
### Data Availability
The complete 40 ns trajectory files and raw simulation datasets are permanently archived and citable via Zenodo: 
[Zenodo Dataset DOI](https://zenodo.org/records/22896835)
